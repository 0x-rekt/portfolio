---

## ⚡ Portfolio Tech Stack

The portfolio site itself is built using:
- **Framework**: Next.js 15 (App Router) & React 19
- **Languages**: TypeScript & HTML5 Canvas
- **Animation**: Motion (Framer Motion)
- **Styling**: TailwindCSS & custom high-contrast cyber variables
- **Performance**: Intersection observers and visibility listeners to pause CPU-intensive animations when out of view
